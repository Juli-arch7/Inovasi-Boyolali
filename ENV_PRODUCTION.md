# 🔧 Production Environment Configuration

Panduan konfigurasi environment variable untuk production deployment.

## Backend .env (Production)

### Edit file: `backend/.env`

```env
# ===== APP CONFIGURATION =====
APP_NAME="Portal Inovasi Daerah"
APP_ENV=production              # ⚠️ HARUS: production
APP_DEBUG=false                 # ⚠️ HARUS: false (jangan pernah true di production!)
APP_KEY=base64:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx  # Generated by php artisan key:generate
APP_URL=https://api.yourdomain.com  # Ganti dengan URL API production

APP_LOCALE=id
APP_FALLBACK_LOCALE=id
APP_FAKER_LOCALE=id_ID

# ===== DATABASE CONFIGURATION =====
DB_CONNECTION=mysql
DB_HOST=localhost              # atau: db.yourdomain.com
DB_PORT=3306
DB_DATABASE=inovasi_db_prod   # Nama database production
DB_USERNAME=inovasi_user      # Username database production
DB_PASSWORD=change_me_strong_password_123  # ⚠️ GANTI: Password kuat!

# ===== SESSION & CACHE =====
SESSION_DRIVER=database        # atau: file, redis
SESSION_LIFETIME=120
SESSION_ENCRYPT=false
SESSION_PATH=/
SESSION_DOMAIN=.yourdomain.com

# ===== CACHE & QUEUE =====
CACHE_STORE=file               # atau: redis, database
CACHE_PREFIX=inovasi_

QUEUE_CONNECTION=database      # atau: redis, sync
BROADCAST_CONNECTION=log

# ===== REDIS (jika menggunakan) =====
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# ===== MAIL CONFIGURATION =====
MAIL_MAILER=smtp               # atau: sendmail
MAIL_HOST=smtp.mailtrap.io     # Ganti dengan SMTP server
MAIL_PORT=2525
MAIL_USERNAME=your_mailtrap_username
MAIL_PASSWORD=your_mailtrap_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@yourdomain.com"
MAIL_FROM_NAME="Portal Inovasi"

# ===== LOGGING =====
LOG_CHANNEL=stack
LOG_STACK=single
LOG_DEPRECATIONS_CHANNEL=null
LOG_LEVEL=notice               # production: notice, warning, error

# ===== CORS (Frontend Domain) =====
APP_CORS_ALLOWED_ORIGINS=https://yourdomain.com

# ===== FILESYSTEM =====
FILESYSTEM_DISK=local
```

## Frontend Environment (Production)

### Edit/Buat file: `frontend/.env.production`

```env
# API Configuration
VITE_API_URL=https://api.yourdomain.com/api
VITE_APP_NAME="Portal Inovasi Daerah"

# Feature Flags (opsional)
VITE_DEBUG=false
VITE_LOG_LEVEL=error
```

### Update file: `frontend/vite.config.js`

Pastikan konfigurasi environment benar:

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:8000',  // Hanya untuk development
        changeOrigin: true,
      }
    }
  },
  // Production build config
  build: {
    outDir: 'dist',
    minify: 'terser',
    sourcemap: false,  // Jangan include source maps di production
    rollupOptions: {
      output: {
        manualChunks: {
          'vue': ['vue', 'vue-router', 'pinia']
        }
      }
    }
  }
})
```

## Penting: Database Production

### Create Database & User

```bash
mysql -u root -p
```

```sql
-- Buat database
CREATE DATABASE inovasi_db_prod 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

-- Buat user
CREATE USER 'inovasi_user'@'localhost' 
  IDENTIFIED BY 'change_me_strong_password_123';

-- Grant permissions
GRANT ALL PRIVILEGES ON inovasi_db_prod.* 
  TO 'inovasi_user'@'localhost';

FLUSH PRIVILEGES;
EXIT;
```

## Security Checklist

- [ ] `APP_DEBUG=false`
- [ ] `APP_ENV=production`
- [ ] `APP_KEY` sudah di-generate (bukan placeholder)
- [ ] Database password kuat & unik
- [ ] `MAIL_FROM_ADDRESS` konfigurasi yang benar
- [ ] `CORS_ALLOWED_ORIGINS` hanya domain frontend
- [ ] SSL/HTTPS aktif
- [ ] Storage directory bisa ditulis tapi tidak bisa diakses langsung

## Post-Deployment Verification

```bash
# Test API connection
curl -H "Content-Type: application/json" https://api.yourdomain.com/api/health

# Check Laravel version
php artisan --version

# Test database connection
php artisan migrate:status

# View logs
tail -f storage/logs/laravel.log
```

## Emergency Recovery

Jika deployment gagal:

```bash
# 1. Clear all cache
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# 2. Check logs
tail -f storage/logs/laravel.log

# 3. Verify permissions
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 755 storage bootstrap/cache

# 4. Re-run migrations
php artisan migrate --force

# 5. Restart services
sudo systemctl restart nginx
sudo systemctl restart php8.2-fpm
```
